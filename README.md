# J.A.R.V.I.S. Companion — «Stark HUD»

دستیار صوتی فارسیِ آفلاین با یک HUD هولوگرافیک به سبک آیرون‌من:
تشخیص چهره/خستگی با دوربین، کلمه‌ی بیدارباش «جارویس»، پخش موزیک، باز کردن
پوشه‌ها و برنامه‌ها، کنترل صدای سیستم، اسکرین‌شات، تایمر/یادآوری، اخبار و
آب‌وهوا، و (اختیاری) پاسخ‌گویی طبیعی با Claude.

هسته‌ی بصری یک **کره‌ی هزار‌نقطه‌ایِ چرخان** است که مثل اکولایزر با صدای شما
یا خود جارویس نبض می‌زند (آبی در حالت عادی، طلایی هنگام صحبت، آبیِ روشن هنگام
شنیدن). ساعت و دمای **مونکتون (نیوبرانزویک، کانادا)** هم کنار ساعت محلی نمایش
داده می‌شود.

برنامه‌نویس: **محسن جباره اصل** (روی HUD و با دستور «سازنده‌ات کیه»).

نسخه‌ی ۸ کاملاً بازنویسی و ماژولار شده است. نسخه‌ی قدیمی تک‌فایلی هنوز به‌صورت
`jarvis_v7.py` موجود است.

---

## نصب

```bash
python -m venv .venv
.venv\Scripts\activate          # ویندوز
pip install -r requirements.txt
```

یا نصب به‌صورت پکیج:

```bash
pip install -e .
```

## پیکربندی

هیچ مقداری داخل کد نیست. یک بار فایل نمونه را بسازید و ویرایش کنید:

```bash
python -m jarvis --init-config
```

این `config.json` را کنار سورس می‌سازد (یا آن را در `~/.jarvis/config.json`
بگذارید). مهم‌ترین کلیدها:

| کلید | توضیح |
|---|---|
| `user_title` | نحوه‌ی خطاب شما (پیش‌فرض «قربان») |
| `website_url` | سایتی که با «سایتم رو باز کن» باز می‌شود |
| `music_dir` | پوشه‌ی موزیک |
| `wake_words` | واژه‌های بیدارباش |
| `folder_aliases` | نام فارسی → مسیر، برای «... رو باز کن» |
| `anthropic_api_key` | (اختیاری) فعال‌سازی فال‌بک Claude — یا از `ANTHROPIC_API_KEY` |

## اجرا

```bash
python -m jarvis              # تمام‌صفحه
python -m jarvis --windowed   # پنجره‌ای
python -m jarvis --no-camera --no-voice   # فقط HUD
python jarvis_v8.py           # معادل، برای Run در VS Code
```

مدل‌های لازم (FaceLandmarker و Vosk فارسی، ~۵۰MB) در نخستین اجرا یک بار در
`~/.jarvis/models` دانلود می‌شوند و دیگر تکرار نمی‌شوند.

### کلیدهای میان‌بر

| کلید | کار |
|---|---|
| `ESC` | خروج |
| `D` | نمایش/مخفی HUD دیباگ |
| `M` | ساکت‌کردن رویدادهای خودکار |
| `F11` | تغییر بین تمام‌صفحه و پنجره |
| `0`–`4` | تست دستیِ رویدادهای دوربین |

## حافظه‌ی بلندمدت (Memory Kernel)

جارویس حقایقِ ماندگار دربارهٔ تو را در SQLite (`~/.jarvis/data/memory.db`) نگه
می‌دارد، با آینهٔ Markdown سازگار با Obsidian در `~/.jarvis/memory_vault/`.

- «جارویس، این رو یادت باشه که …» → ذخیره
- «جارویس، دربارهٔ … چی یادته؟» → بازیابی
- «حافظه‌ت رو نشون بده» → آمار
- هیچ حذفِ دائمی‌ای نیست؛ فقط بایگانی و جایگزینی (با ردِ ممیزی کامل)
- حقایقِ تکراری خودکار تقویت می‌شوند
- هر شب ساعت ۴ (`nightly_consolidation_hour`) از مکالمه‌های اخیر، حقایقِ
  جامانده استخراج می‌شوند (نیاز به کلید Claude)
- هنگام پاسخ‌گوییِ آزاد، حقایقِ مرتبط خودکار به Claude داده می‌شوند

## موتور مأموریت

درخواست‌های چندمرحله‌ای («جارویس یه کاری برام بکن: اول … بعد …») به گام‌های
قابل‌راستی‌آزمایی تبدیل و یکی‌یکی اجرا می‌شوند. وضعیت هر مأموریت در
`~/.jarvis/data/missions.db` ذخیره می‌شود، پس بعد از کرش/بستنِ برنامه قابل
ادامه است. موتور از همه‌ی ابزارهای زیر استفاده می‌کند.

## ابزارها و ادغام‌ها (فاز ۲)

هر ادغام تا وقتی کلید/کتابخانه‌اش تنظیم نشود خودش خاموش می‌ماند و بقیه‌ی
برنامه بدون آن کار می‌کند. وضعیتشان در چیپ‌های پایینِ HUD دیده می‌شود.

| ابزار | کلید لازم؟ | نمونه دستور |
|---|---|---|
| **جست‌وجوی وب** (DuckDuckGo + خواندن صفحه + خلاصه‌ی Claude) | نه | «تو اینترنت بگرد پایتخت کانادا کجاست» |
| **فایل‌سیستم** (فهرست/خواندن/نوشتن، فقط مسیرهای `fs_whitelist` + `~/JarvisFiles`) | نه | (از طریق مأموریت) |
| **خط فرمان** (فقط دستورهای `cli_whitelist`، پیش‌فرض خاموش) | نه | `cli_enabled: true` |
| **Gmail + Calendar** | `~/.jarvis/credentials/google_credentials.json` + `pip install ".[google]"` | «ایمیل‌های نخونده» · «برنامه‌ام این هفته چیه» |
| **Spotify** | `spotify_client_id` / `_secret` + `pip install spotipy` | «تو اسپاتیفای پخش کن …» · «چی داره پخش میشه» |
| **Notion** | `notion_token` (Integration + به‌اشتراک‌گذاری صفحه) | «تو نوشن بگرد …» |
| **بات تلگرام** | `telegram_bot_token` + `telegram_owner_id` | از موبایل هر چی بپرسی؛ همان حافظه و Claude |

کلیدها را در `config.json` یا این متغیرهای محیطی بگذار: `SPOTIFY_CLIENT_ID`،
`SPOTIFY_CLIENT_SECRET`، `NOTION_TOKEN`، `TELEGRAM_BOT_TOKEN`، `TELEGRAM_OWNER_ID`.
(راهنمای قدم‌به‌قدمِ گرفتن هر کلید جداگانه ارائه می‌شود.)

## حالت مکالمه‌ی پیوسته

به‌صورت پیش‌فرض روشن است (`conversation_mode` در config). کافی است **یک بار**
بگویید «جارویس»؛ از آن به بعد لازم نیست هر بار صدایش کنید — هر جمله‌ای که بگویید
مستقیماً دستور تلقی می‌شود. برای خروج بگویید **«بسه»** یا «کافیه» یا «دیگه گوش نده».

- حلقه‌ی نورانیِ دور کره تا وقتی در حالت مکالمه باشد روشن می‌ماند.
- جمله‌های نامفهوم در این حالت نادیده گرفته می‌شوند (نق نمی‌زند) — با
  `nag_on_unknown: true` عوض می‌شود.
- `conversation_idle_timeout` (ثانیه) اگر > ۰ باشد، پس از آن مدت سکوت خودکار
  از حالت مکالمه خارج می‌شود؛ ۰ یعنی هرگز.
- با دستور «حالت مکالمه» هم می‌توان بدون کلمه‌ی بیدارباش واردش شد.

## نمونه دستورهای صوتی

> «جارویس» … «ساعت چنده» · «امروز چندمه» · «ساعت مونکتون» · «هوای مونکتون» ·
> «وضعیت سیستم» · «باتری چقدره» · «هوا چطوره» · «اخبار» · «سازنده‌ات کیه» ·
> «یه آهنگ بذار» / «آهنگ بعدی» / «آهنگ رو مکث کن» · «دسکتاپ رو باز کن» ·
> «قیمت طلا رو سرچ کن» · «ده دقیقه دیگه یادم بنداز آب بخورم» ·
> «صدای سیستم رو کم کن» · «اسکرین‌شات بگیر» · «سیستم رو قفل کن» ·
> «یه جوک بگو» · «تاس بنداز» · «شیر یا خط» · «ممنون» ·
> «سیستم رو خاموش کن» (با تاییدِ «بله/نه») · «برنامه رو ببند»

اگر کلید Claude تنظیم شده باشد، هر جمله‌ای که با دستورهای بالا جور نشود به
Claude می‌رود و می‌تواند حتی خودِ دستورها را اجرا کند (به‌جز اقدامات پرخطر).

## ساختار

```
jarvis/
  __main__.py      نقطه‌ی ورود و آرگومان‌ها
  config.py        بارگذاری config.json / .env
  paths.py         مسیرهای دائمی (~/.jarvis)
  state.py         وضعیت مشترک بین تردها
  models.py        دانلود مدل‌ها (با User-Agent، retry، دائمی)
  tts.py           edge-tts + کش دائمی + داکینگ موزیک
  music.py         پخش موزیک
  system_actions.py باز کردن مسیر/برنامه، صدا، خاموش/قفل، کلید رسانه
  reports.py       متن گزارش‌ها (ساعت/سیستم/هوا/اخبار)
  text_fa.py       نرمال‌سازی، تطبیق فازی، تجزیه‌ی عدد/زمان فارسی
  commands.py      فهرست دستورها + تطبیق + اجرا + مسیریابی مأموریت
  claude_client.py فال‌بک Claude با tool-use + تزریق حافظه
  memory/          Memory Kernel — store (SQLite/FTS), markdown_mirror, curator
  missions/        موتور مأموریت — tools, store (SQLite), engine
  vision.py        ترد دوربین + رویدادها
  audio_in.py      ترد Vosk + بیدارباش + تایید صوتی
  workers.py       آمار سیستم + آب‌وهوا
  hud/             تم، فونت، کره، ویجت‌ها
  app.py           حلقه‌ی اصلی
```
